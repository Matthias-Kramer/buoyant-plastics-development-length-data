# Supporting data for Figure 4

Supporting numerical data for Figure 4 of the manuscript
**“Development Length and Transport Regimes of Buoyant Plastics in Open-Channel Flows.”**

## Contents

### Figure 4a
`data/Figure_4a_selected_particle_trajectories.csv`

Selected trajectories of the 20 particles plotted in panel (a).
Each particle has a streamwise coordinate `x_particle_XX_m` and a dimensionless
vertical coordinate `z_over_H_particle_XX`.

Vertical reference lines in the figure:
- L_mean = 1.674 m
- L_95 = 2.578 m

### Figure 4b
`data/Figure_4b_CDF.csv`

Data used for the cumulative distribution function (CDF) curve.

`data/Figure_4b_deltaC.csv`

Data used for the concentration-difference curve Delta C. In the plotting source,
`deltaC_percent` is divided by 100 for display.

### Figures 4c and 4d
`data/Figure_4c_d_simulation_summary.csv`

Processed simulation results across the modified Rouse-number range, including:
- L_mean/H
- L_95/H
- the L-percentile corresponding to Delta C = 0.05 for absorptive and reflective boundaries.

### Figure 4d theoretical curve
`data/Figure_4d_theoretical_curve.csv`

Tabulated theoretical L/H curve embedded in the plotting source.

## Scope

These files provide the numerical data underlying Figure 4. The simulation source
code is not included.
